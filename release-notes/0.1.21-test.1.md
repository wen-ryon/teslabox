# TeslaBox 0.1.21 启动链路测试版

这是面向已安装 TeslaBox 的 ROCK 3A 设备的灰度更新，用于缩短车辆上电后的 TeslaUSB 关键启动路径，并采集冷启动时序。请先在少量车辆验证后再扩大更新范围。

## 启动优化

- TeslaUSB 核心状态机现在会在 Web 认证、设置中心、网络管理和媒体管理组件初始化期间并行启动，避免非关键组件占用本次冷启动的 Gadget 绑定机会。
- 原厂 Radxa Gadget 服务屏蔽、数据盘身份核验、backing image 检查、UDC 唯一性校验和每次开机最多一次的绑定限制保持不变。
- 本版不会在运行期重新绑定 UDC，也不会扩大内核启动后 60 秒的安全绑定窗口。

## 冷启动诊断

- 日志会新增“TeslaUSB 核心状态机已启动”，包含主程序启动到核心状态机启动的毫秒数。
- 本次冷启动完成绑定且车机完成枚举后，日志会新增“TeslaUSB Gadget 已完成本次冷启动绑定和枚举”，包含状态机耗时、内核启动时长、UDC 和协商速率。
- 请在一次完整冷启动后导出 `sudo journalctl -b -u teslabox.service --no-pager`，用于区分板端数据盘/服务延迟与车机后续重新扫描 USB 的等待。

## 测试边界

- 网页在线更新只替换签名校验后的 TeslaBox ARM64 主程序及内嵌页面，不更新内核、无线驱动、FFmpeg/MPP/RGA 工具链、AP 脚本或首次安装包。
- 板子与车机同一时刻上电时，外置数据盘枚举和挂载仍是 Gadget 可用前的硬件前置条件；本版缩短的是 TeslaBox 自身非关键初始化占用，不能承诺消除车机错过首次 USB 扫描后的等待。
- 不要为追求启动速度在已开机的 ROCK 3A 上再热插 OTG 线；仍须遵守现有独立 Type-C 供电和 OTG 安全接线方式。
