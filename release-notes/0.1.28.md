# TeslaBox 0.1.28 稳定版

本版本主要完善管理页面，并加入 ROCK 3A 专用 PWM 风扇控制。更新不会改变现有录像盘、USB Gadget 或网络配置。

## PWM 风扇控制

- 设置中心新增“散热与风扇”，显示 CPU 温度、当前工作场景、温度请求和最终 PWM 输出。
- 支持推荐温度曲线与四档手动温度曲线，并可统一限制最大转速。
- 支持分别配置待机、单路播放、多路合成、视频导出和存储维护场景的转速请求。
- 在线播放、合成、导出和存储维护开始时会及时提高风扇请求，任务结束后自动回落。
- 未检测到 PWM 硬件时只显示不可用原因，不影响录像、Gadget、网络或媒体功能运行。

> 风扇控制面向 ROCK 3A 的 5V/PWM/GND 专用风扇接口，需要系统已启用 `rk3568-pwm8-m0-fan` overlay，并提供 `/sys/class/pwm/pwmchip8`。本次在线更新不会自动改写设备树或启动配置。

## 页面调整

- 设置中心改为分类标签页，减少长页面连续滚动，并记住当前浏览器最后打开的分类。
- 将“特斯拉车机兼容模式”移动到右上角页面设置菜单，与主题和字体选项集中管理。
- 首次访问新增四步页面功能指引；完成状态保存在设备端，更换访问域名或 IP 后不会重复出现。
- 检测到新的未初始化外接存储时单独提示初始化，可暂不处理，并按设备稳定标识记住选择。
- 媒体中心会明确识别当前录像盘是否存在 FAT32 音乐分区；未创建时禁用音乐上传并给出处理提示。
- 优化风扇设置在手机和窄屏设备上的布局。

## 更新提示

- 可在 TeslaBox 设置中心直接检查并安装本稳定版；更新过程中请保持板子供电。
- 已经启用风扇 overlay 的设备更新后即可使用风扇控制；未启用的设备不会因为本次更新而启动或修改 PWM 硬件。
