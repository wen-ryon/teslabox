# TeslaBox 0.1.31 RC3：修复 Debian 11 首装软件源

RC2 在 Debian 运行依赖预下载时仍失败。Debian 11 Bullseye 的 LTS 已结束，在线安全仓虽然还能提供签名索引，但其中部分软件包文件已被删除；更换普通镜像无法解决同一批 404。

RC3 将首装时的 Debian 安全仓固定到 2026-08-31 的 Debian 官方快照。脚本在改写 APT 源前校验快照 `InRelease` 的固定 SHA-256 与 Debian 签名，仅对这条历史快照源关闭索引过期时间检查；随后由 APT 验证索引及软件包哈希，并预下载全部依赖。只有依赖完整下载成功，才开始安装 TeslaBox 程序。原 APT 源仍会备份。

该快照是 Debian 11 停止 LTS 支持时的冻结内容，不会继续获得安全更新；后续应迁移到受支持的系统。RC3 仍为 ROCK 3A / Radxa Debian 11 ARM64 内测版。请完成真实首装，并检查 `teslaboxctl -v`、重启后的服务、Wi-Fi/AP、蓝牙和 USB Gadget。
