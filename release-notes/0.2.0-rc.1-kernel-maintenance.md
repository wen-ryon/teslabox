# RC1 内核升级维护脚本修正

修复原厂内核包含 cfg80211/mac80211 内建模块时，kmod 28 在缺少目标内核参数的情况下读到内建记录、返回空 ABI，导致 prepare 报错的问题。

维护脚本统一使用 `modinfo -k 5.10.160-teslabox3`，并明确拒绝空 ABI、错误 ABI 和查询失败。在预检失败时不安装内核、不改启动菜单、不报告升级成功。

本次只更新维护附件。程序版本仍为 `0.2.0-rc.1`，不重新构建主程序、助手、内核、apfix6 或运行时组件。

- 助手 SHA-256：`6b9b4047dc6021c1b9e3ddbe56b1afefff3accbf50b776f665e3e783fda1128c`
- 内核组件 SHA-256：`830a73b370715dc0503d4307d790220fed3262a8f3488d7b135fa0e6294efcb3`

测试包括 ABI 参数及错误回归、预检失败不修改启动状态，以及真实 Bullseye kmod 28 对合成 AArch64 ELF 元数据的读取。合成模块不代表驱动加载或实机 OTA 验收；实际板端升级仍由用户验证。普通 beta/stable 通道不随此维护修正开放。
