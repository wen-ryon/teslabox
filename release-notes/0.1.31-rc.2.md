# TeslaBox 0.1.31 RC2：修复 Debian 11 首装依赖下载

RC1 首装时，Debian 安全仓元数据可读取，但其中列出的部分 `.deb` 已不可下载，导致 APT 连续返回 404 并中断安装。

RC2 在安装依赖前先下载所需软件包。若安全仓的包文件不可用，首装脚本会依次验证并切换到其他带 Debian 签名的镜像，重新刷新软件包列表后再尝试下载。只有全部依赖下载成功，才开始安装依赖和 TeslaBox 程序。原有 APT 源会保留备份。

本轮仍为内测版，适用于 ROCK 3A 的 Radxa Debian 11 ARM64 首装。请验证首装完成后的 `teslaboxctl -v`、Wi-Fi 与热点、蓝牙、重启后状态和 USB Gadget。MT7922 测试内核的交互确认要求保持不变。
