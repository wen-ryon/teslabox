# TeslaBox 0.1.18 录像批量删除测试版

这是面向已安装 0.1.17 及更早版本设备的灰度测试更新，重点验证录像多选删除、删除后自动回收外层空间，以及整个过程只暂停一次 USB Gadget、只安排一次温重启。请先在少量 ROCK 3A 设备上验证，不建议立即全量更新。

## 录像批量删除

- 录像列表新增“全选当前列表”和“删除已选并恢复空间”，可一次选择多段最近录像、已保存录像或哨兵录像。
- 服务端只接受当前媒体快照中仍然存在的会话，并重新解析删除路径；录像列表已变化时会拒绝操作，避免页面使用过期路径误删其他文件。
- 已保存录像和哨兵录像仍按整个事件目录删除，目录中的 `event.json`、缩略图和其他小型元数据会一并删除。
- 最近录像仍只删除索引中属于所选会话的 MP4 文件，不会扩大到未知目录或页面任意传入的路径。
- 一次请求最多删除 2000 段录像，重复选择会在服务端去重。

## 自动空间回收

- 录像删除与 exFAT 空闲簇回收合并到同一个维护窗口，删除后无需再去设置中心执行一次空间回收。
- 自动维护模式下，整批录像只断开一次 USB Gadget，删除和回收完成后只安排一次温重启。
- 手动维护模式下，仍要求先物理拔掉车机或电脑 OTG；操作完成后 Gadget 保持暂停，需要插回 OTG 并执行一次温重启恢复。
- 如果录像已经删除但外层 XFS 空间回收失败，接口会保留删除成功结果并单独返回回收错误，避免用户误以为删除失败而重复操作。
- 设置中心原“回收旧空间”调整为“回收历史旧空间”，仅用于处理旧版本或在电脑上直接删除后遗留的外层占用。

## Gadget 安全边界

- 批量删除的路径解析在 Gadget 维护开始前完成；真正写盘和空间回收在串行化的媒体维护窗口内完成。
- 回收前会卸载 exFAT 并释放 loop 设备，再依据 exFAT 分配位图对确认空闲的范围执行 hole punch。
- 自动维护使用独立限时上下文；浏览器关闭或请求断开不会中途终止 Gadget 恢复和温重启预约。
- 本版不会为了刷新页面或重新扫描录像而额外解绑、重绑 Gadget。

## 页面与接口

- 新增批量删除接口 `POST /api/v1/video-sessions/delete`，请求体使用服务端会话标识数组，不接受客户端文件路径。
- 删除期间会锁定选择框和删除按钮，完成后清空选择并刷新录像、存储和维护状态。
- 页面资源版本已更新，设备升级后浏览器会获取新的 CSS 和 JavaScript。

## 测试范围与观察项

- 本版只替换签名校验后的 TeslaBox ARM64 主程序及其内嵌网页，不修改内核、systemd、udev、WiFi/AP 脚本、NetworkManager 或 FFmpeg/RKMPP 工具链。
- 源码附带 USB Gadget SuperSpeed 识别与 High-Speed 排查文档；它不改变设备运行时的 Gadget 配置。
- 请重点验证单段删除、多段删除、混合录像类型删除、页面刷新后的容量变化、温重启后 Gadget 重新枚举，以及车机继续录像是否正常。
- ROCK 3A 仍必须遵守独立 Type-C 供电和 OTG 安全接线顺序；删除和回收期间不要断电、拔出数据盘或连接新的 USB 主机。
