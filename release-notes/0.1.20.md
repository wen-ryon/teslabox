# TeslaBox 0.1.20

## 录像删除体验优化

- 录像筛选栏新增实心红色“删除录像”按钮，与“筛选录像”同一行、同尺寸显示。
- 点击“删除录像”后才进入选择模式；已保存录像和哨兵录像可点击整张卡片选择，选中卡片显示红色边框。
- “全选”仅作用于当前筛选结果中的已保存/哨兵录像，最近录像不会被批量选择。
- 有选中录像时，主按钮会变为“删除已选并恢复空间”；删除仍在同一个 Gadget 维护窗口内完成，并自动尝试回收外层数据盘空间。
- 已保存/哨兵录像不再提供卡片内的单独删除入口，避免绕过批量选择流程；最近录像继续保留“删除此段最近录像”。

## 手工测试部署

- 仓库新增可持久安装到 `/usr/local/sbin/teslabox-deploy-local` 的通用部署器。它要求调用方提供候选包 SHA-256，并在替换前创建时间戳备份；服务或健康检查失败时会自动回滚。

## 首次安装

- 公开首装脚本和 Debian 11 ARM64 首装归档同步到 0.1.20；新设备运行文档中的首装命令后，会直接安装本版主程序、内嵌网页、Gadget/AP 脚本和媒体工具链。
- 可选 MT7922 测试内核仍固定使用已验证的 v0.1.16 归档，不会因主程序首装包升级而隐式更换内核基线。

## 升级范围

- 本次网页更新只更新 TeslaBox 主程序，不更新内核、无线驱动、FFmpeg/MPP/RGA 工具链或 systemd 配置。
