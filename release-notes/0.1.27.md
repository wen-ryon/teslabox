# TeslaBox 0.1.27 稳定版

> **建议所有用户更新。** 本版本集中修复 USB Gadget 反复拔插后无法枚举、容量显示异常及录像快照 I/O 错误，并完善视频导出与页面交互。

## 首次启动热修复

- 修复 `teslabox-fsck.exfat 1.2.0` 输出正确版本后按 fsck 约定返回状态 16，却被错误判定为媒体运行时安装失败的问题。
- 保留严格版本校验：只有版本输出确认是 1.2.0，且退出状态为成功或 exfatprogs 官方版本查询状态时才允许启动。

## USB Gadget 与录像快照

- 修复 ROCK 3A 在多次拔插 OTG 后可能出现端点卡死的问题，降低车机或 Windows 无法重新识别、识别到设备但容量显示为 `0.0 MB / 0.0 MB` 的概率。
- 快照扫描遇到 `RecentClips: input/output error` 时，会丢弃异常快照并对新建的只读副本进行受控检查后重试；不会在 Gadget 已连接时修复车机正在使用的原始镜像。
- 媒体运行时新增专用 `teslabox-fsck.exfat 1.2.0`，录像删除、空间回收和快照维护统一使用随更新安装的版本，兼容旧版工具无法处理的异常目录项。
- 扩充 Gadget、DWC3、磁盘及快照诊断信息，后续遇到枚举或 I/O 异常时能够保留更完整的定位证据。
- 保留新写入的 COW extent 保护和只读碎片诊断；移除无法在有限剩余空间内可靠完成的“离线整理”入口，不再提示用户为整理而重新初始化存储设备。

## 视频导出

- 修复六路及其他多路合成导出中方向盘旋转方向相反的问题，统一单路和多路的仪表方向。
- 统一悬浮信息栏的宽度、间距、居中方式与可读性；修复单路、高保真、多路合成及画面上方信息栏的布局差异。
- 单独放大“单路视角 + 前视 + 原画”的录像时间和 Tesla 仪表信息，不影响其他视角和画质。
- 修复完成一次导出后修改参数再次导出时提示“媒体快照暂不可用”的问题。
- 导出历史新增删除按钮，可直接删除未下载或不再需要的成品并释放空间。
- 导出文件名调整为“视角-画质-时间-叠加信息.mp4”，便于离线识别和整理。

## 页面与录像管理

- 录像列表的自动刷新移动到“立即刷新”旁，可选择关闭、15 秒、30 秒或 60 秒；默认 60 秒。
- 多选删除、拖动进度条或打开播放器时暂停后台刷新，避免操作过程中列表被重建或长时间显示“正在同步录像索引”。
- 首页标题调整为“TeslaBox 运行状态”，移除原有宣传文案。
- 补充“自动紧急制动触发”等录像事件的中文说明，并统一导出历史、存储健康等页面提示。

## 更新说明

- 可在 TeslaBox 设置中心直接检查并安装本稳定版；更新过程中请保持板子供电，不要拔出系统盘或数据盘。
- 在线更新会替换 TeslaBox 主程序、内嵌网页及随包媒体运行时，不会修改内核、MT7922 Wi-Fi/蓝牙驱动或用户的网络配置。
- USB 仅协商为 High-Speed 而非 SuperSpeed 可能还受线材、接口、供电和控制器协商影响，本版本不把该独立现象声明为已完全修复。
