# TeslaBox 0.1.16 正式版

本版在 0.1.15 的 Gadget、WiFi/AP 和六路播放修复基础上，增加录像网页删除能力，并明确区分录像索引与数据盘外层空间。已经安装 0.1.15 的设备可直接在设置中心执行网页更新。

## 录像删除

- 已保存录像和哨兵录像按完整事件目录删除，同一事件目录内的 MP4、`event.json`、缩略图和其他附属文件会一并清理。
- 最近录像没有独立事件目录，删除时清理当前快照已索引的全部 MP4，保留共享的 `RecentClips` 目录和非录像元数据，避免误删其他内容。
- 删除目标只使用服务端当前快照生成的路径，并校验目录边界、文件类型和符号链接；客户端不能提交任意文件路径。
- 如果录像正在播放、导出或被其他快照租约占用，删除会被拒绝，不会与媒体任务并发修改底层镜像。

## Gadget 与存储维护

- 自动维护模式会先独占停止 USB Gadget，再清理快照、以读写方式挂载 TeslaCam 镜像、删除录像、执行同步和文件系统检查，最后卸载并释放 loop 设备。
- 自动维护使用独立的限时后台上下文；即使浏览器在请求后关闭，也不会让 Gadget 生命周期停在中间状态。完成后按现有安全策略安排温重启，在新一轮开机中恢复绑定。
- 手动维护模式继续要求确认车机或电脑 OTG 已物理断开，避免在主机仍可能写盘时修改镜像。
- 删除已保存或哨兵录像前会确认该网页条目只对应一个事件目录；异常跨目录条目会被拒绝。

## 空间显示

- 设置中心把原先容易误解的“快照空间”和“视频数量”改为“数据盘外层可用”和“录像索引”。
- TeslaCam 是 XFS 数据盘中的稀疏虚拟磁盘镜像。删除镜像内 exFAT 录像会释放车机可再次使用的内部空间，但不会立即缩小外层镜像已分配区块，因此外层 XFS 可用空间可能暂时不变。

## 首次安装与更新范围

- 公开首装脚本、完整 ARM64 首装包和固定 SHA-256 更新到 0.1.16。
- 网页在线更新只替换签名校验后的 TeslaBox 主程序；本版删除功能和生命周期约束均包含在主程序中，现有 0.1.15 用户不需要单独更新 systemd、udev、AP 脚本或媒体工具链。
- 首装和需要重新接线时仍必须遵守 ROCK 3A 的 OTG 供电限制：先使用独立 Type-C 供电并断开车机 OTG，系统稳定后再连接 OTG。
