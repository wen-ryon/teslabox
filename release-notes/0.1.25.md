# TeslaBox 0.1.25 正式版

本版重点修复不同无线网卡、监管域和 AP+STA 并发模式下的热点生命周期问题，并完善播放控件与系统更新说明的跨浏览器显示。更新会安全替换主程序并重启服务，请尽量在车辆停止录像时安装。

## WiFi 与 AP 热点

- 根据 NetworkManager 当前设备清单动态刷新上游 WiFi 接口，网卡重连、设备清单变化或接口名称变化后不会继续监听已经移除的旧接口。
- 区分独立 AP 网卡、同一 PHY 单信道 AP+STA 和多信道并发能力；只有驱动明确要求时才让热点跟随上游信道。
- AP 状态同时核对 NetworkManager 与 `iw` 的真实接口类型、SSID 和信道，不再把残留连接记录或普通 STA 接口误报为正在运行的热点。
- 增加 AP 接口冲突诊断与安全修复入口；只停用错误占用 AP 接口的连接，不删除用户保存的上游 WiFi。
- 启动热点前检查当前网卡和监管域允许的信道，对 `disabled`、`no IR` 和 DFS/RADAR 给出明确原因，避免 NetworkManager 反复超时。
- 修复 5 GHz 与 6 GHz 复用相同信道号导致的误判：例如可用的 `5785 MHz / 信道 157` 不再被禁用的 `6735 MHz / 信道 157` 覆盖。
- AP 启动脚本限制自动重试次数，避免不支持并发或信道受限的硬件持续激活连接；热点关闭时继续保持上游 WiFi 可用。

## 页面与播放兼容性

- 设置中心展示 AP 接口角色、实际频段、实际信道、并发能力和结构化故障建议，首选信道与当前工作信道不再混淆。
- 系统更新说明按受限 Markdown 安全渲染，标题、列表和段落可以正确显示，同时拒绝任意 HTML 注入。
- 播放与暂停按钮改为内置 SVG 图标，不再使用依赖系统字体的 Unicode 字符；Windows、Android、Tesla 浏览器和不同字体环境下保持一致。
- 更新静态资源版本号，安装后浏览器会直接获取新版样式和脚本，避免旧缓存继续显示异常控件。

## 部署与兼容边界

- 本地测试部署只保留一份规范回滚程序，不再按时间戳无限残留旧二进制。
- 已知官方旧版 AP 脚本可由签名网页更新安全迁移；检测到用户自行修改的未知脚本时仍拒绝覆盖。
- 首装入口更新到 0.1.25 完整包；MT7922 WiFi 内核包和可选蓝牙包仍沿用原有、已验证的独立发布版本。
- 网页更新仍只接受 Ed25519 签名、SHA-256 和长度全部匹配的正式包，不更新内核，也不安装个人蓝牙触发任务。
