# TeslaBox 0.1.8 灰度测试版

这是面向现有 0.1.7 用户的灰度更新，重点验证不同无线硬件和 OTG 接入顺序下的稳定性。设备端内部版本为 `0.1.8`，源码标签为 `v0.1.8-test.1`；后续正式版本将顺延为 `0.1.9`。

## 核心修复

- 收紧 USB Gadget 生命周期管理：同一次开机只允许完成一次安全绑定，暂停、恢复和服务退出不会重复解绑后再绑定，降低 ROCK 3A 在异常 OTG 供电场景下的内核风险。
- 修复 0.1.7 开机后 Gadget 被后续初始化流程断开的回归，并补充并发、关闭和失败路径测试。
- 修复设置中心无法关闭 AP：关闭操作改为先完成持久化和网络状态切换，再异步等待热点退出，避免 HTTP 请求被网络切换提前打断。
- 无无线网卡、仅支持客户端模式、仅支持 AP 模式、AP 与 Wi-Fi 不能并发、可使用独立 PHY 并发等情况均按运行时能力探测处理，不再假定固定网卡名称或固定并发能力。
- 改进无线网卡热插拔与网络状态刷新；未检测到无线网卡时保留有线网络和后续探测能力。
- 收紧 FFmpeg/RKMPP 合成与导出任务的并发、取消、超时、临时文件和缓存生命周期，失败时不再遗留半成品。
- 内置时区数据，避免精简系统缺少 `tzdata` 时因加载时区失败导致服务反复重启。

## 更新范围

网页在线更新只替换 TeslaBox 主程序，能够获得本次 Gadget、设置中心、无线能力探测和媒体任务修复。`systemd`、`udev`、AP 初始化脚本及系统软件包变更不在本次网页更新范围内；这些内容将在目标板灰度通过后的完整安装包中发布。

## 灰度观察项

- 更新完成后设备会自动重启；这是为了在 Gadget 已安全解绑后通过新一次开机重新绑定，不能强制取消重启。
- 请重点观察先插电开机后再插 OTG、先插 OTG 再开机、无无线网卡、关闭 AP、Wi-Fi 与 AP 切换、连续导出视频等场景。
- 如果出现异常，请保留设置中心诊断日志和设备启动日志，不要反复手工解绑或绑定 Gadget。
