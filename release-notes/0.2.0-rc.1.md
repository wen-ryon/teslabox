# TeslaBox 0.2.0-rc.1

本版本为 beta 内测版，不进入 stable 通道。

## 更新内容

- 集成独立 CarPlay 接收服务及配套运行时，支持手机发现、选择与配对管理。
- 增加 CarPlay 显示布局、画质及自动播放设置；自动播放默认关闭。
- 协调 CarPlay 与热点、WiFi 上游及蓝牙资源；需要中断 CarPlay 的 WiFi 重连由用户明确确认。
- 设置中心按类别组织，保留原导出设置、旧书签和本地设置选项。
- 增加 CarPlay 分类诊断，完整报告保留关键启动日志并对常见敏感字段脱敏。
- 产品安装在本机生成证书下载凭据，公开程序与手机配对、认证及证书等私有状态分离。
- 增加运行包完整性、依赖预检和安装事务恢复，兼容旧 ARM64 ELF 更新入口。

## 内测注意

无线网卡、蓝牙和驱动存在设备差异。首次安装、旧版本升级、真实手机会话及车机 USB 录像需分别验收，单元测试通过不代表所有设备兼容。

升级应保留本机原有设置与合法身份，不要复制其他设备的私有配置。软件 MFi 身份经维护者私下分发，不包含在公开附件中，也不表示为每台设备签发新的 Apple 身份。

仅使用本版本随发布提供的固定安装入口和签名清单，不沿用历史 RC 安装脚本。稳定版发布需另行确认。
