# TeslaBox 0.2.0-rc.1

当前是完整发行范围的内部候选说明，尚未更新公开 beta/stable 索引；发布与通道可见性需要另行确认。

## 更新内容

- 增加录像播放诊断矩阵，覆盖单路、多路、原画和压缩播放，并提供有限文件及 iPhone HLS 分片对照；可停止测试并下载对应诊断报告。
- 增加 iPhone 原生 HLS 播放链路，切换、关闭与超时后清理转码会话；保留其他浏览器原有播放方式。
- 增加逐路播放阶段日志、媒体请求计时、首片段与播放状态证据，按诊断编号收集报告并限制日志预算；不保存或上传录像内容。
- 修复最近录像时长显示：同一路视角已完整核实时可显示时长，不因其他视角不可读取而隐藏；不将不同视角拼接当作完整覆盖。

- 集成独立 CarPlay 接收服务及配套运行时，支持手机发现与配对管理；提供画质、帧率、主页面布局和自动播放设置，自动播放默认关闭。暂不开放多手机选择入口，保留现有配对、自动连接和已保存的手机目标。
- 协调 CarPlay 与热点、WiFi 上游及蓝牙资源；需要中断 CarPlay 的强制 WiFi 重连由用户二次确认。
- 开启 CarPlay 且尚未登记手机时，板子以 TeslaBox CarPlay 名称开放蓝牙配对；用户在 iPhone 蓝牙设置主动连接并在手机上确认，无需管理页搜索、选手机或开始登记。系统配对完成后自动交接热点并等待本轮新视频；已配对但未登记的手机可断开后重新主动连接重试。
- 首次登记交接保留原热点恢复记录；失败、取消或断电后先清理自有租约再恢复原热点，配置发生变化时停止覆盖。关闭功能、登记进行中或清理未确认时停止接收新的首次配对；蓝牙入口需要实际 Agent、iAP 服务声明和可发现状态，不能仅凭控制器已开启判断手机能发现。登记日志记录请求标识和失败阶段，不将系统已配对标记当作视频成功。
- 修复未登记时缺少 iAP 服务声明导致测试 iPhone 无法发现设备的问题：等待阶段持有独立首登 Profile，最后一次真实连接与服务发现校验后才注销并交给接收端；注册、取消、迟到连接、旧断开事件及并发退出按本轮租约清理，不复用旧配对缓存作为成功证据。内部候选仍需完成真实手机配对及视频验收。
- 首次登记拆分为准备与视频阶段：总期限不超过 180 秒，准备不超过 60 秒，视频从真实交接开始计算且不超过 120 秒；原期限、取消和旧请求不能续期。网络与桥接准备后再次核对剩余预算，过期时清理而非强行启动接收端；手动登记仍保持原 120 秒期限。
- 对本轮已持有连接且手机已配对、已连接但服务发现未完成的情况，仅进行一次有界 iAP Profile 刷新；方法返回成功不代替实际连接、服务发现及新视频证据。取消、服务释放或退出时撤销本轮刷新及待交接状态，拒绝迟到授权和旧连接，最终效果仍待候选实机验收。
- 兼容部分厂商无线驱动不在 iw info 返回关联信道的情况，使用 iw link 的实际连接频率读取上游信道；未关联和不支持的频率仍明确报错。
- 增加 NAS 手动上传和 SMB、WebDAV、SFTP 目标管理，支持原画或压缩上传、默认目标与画质设置；提供上传记录、读回核验及冲突保护。
- 增加事件自动上传，按配置处理哨兵与紧急制动事件，支持视角、范围、画质、去重和任务恢复；默认关闭。
- 增加系统盘录像缓存，复用所选输入，保护活动导出/上传的引用并按闲置留存策略清理；准备完成后释放源快照。
- 增加独立备份、导出与历史页面，上传目标、画质、自动策略分别保存；保留表单草稿、旧导出书签与设置跳转，CarPlay 菜单位于网络连接下面。
- 增加事件增量扫描和共享快照通知，保留录像来源、文件稳定性和车辆时区判断。
- 主程序与媒体、CarPlay、NAS 公开运行时分开交付：版本、下载地址、长度和摘要随签名主程序固定，同摘要组件复用本地缓存。首装与 OTA 共用安装适配器，支持离线预缓存，失败保留旧版本。
- 录像核心与管理入口不等待大组件下载；组件未就绪时在设置中心提示，相关功能返回明确的等待状态，保留已有任务查询和取消。
- 增加 CarPlay 分类诊断与安装事务恢复。证书下载凭据在本机生成，配对、合法认证身份、证书和服务器凭据不进入公开程序或运行时归档。

## 内部验收注意

0.1.31 升级此 RC1 必须先安装本次强制内核维护助手。助手自动安装固定 `5.10.160-teslabox3` 内核、匹配的无线回移模块和最终 apfix6，保留原内核启动入口及备份，跨重启确认后再完成主程序升级。内核安装、启动核对或程序健康检查失败时不能显示升级成功。旧的 959 维护助手不包含此机制，不能继续沿用旧维护包；新版主程序在内核依赖确认前不启动、不迁移数据。

本次内核组件同步纳入已审核的 MT79xx 蓝牙初始化修复，修订 DEB 为 `5.10.160-teslabox3-2`，运行内核 ABI 和程序版本保持不变。原 Image、设备树与 BSP 安装钩子不重新编译或替换为未知产物；蓝牙模块、apfix6 与对应完整源码按固定摘要交付。维护助手拒绝旧 DEB、缺失或旧蓝牙模块；启动核对实际解析的模块与已加载版本，安装失败恢复原模块及旧启动入口，不能靠板端手动热修复冒充归档已含修复。

重复内部候选升级只可接替已结束、无续装请求的内核事务，完整旧事务和回滚材料以独立历史目录原子保留。政策变化不得覆盖跨重启中的请求，也不能删除旧事务绕过校验；损坏的摘要或历史路径冲突明确失败。维护输入仅接受正式 0.1.31、审核过的 RC1 基线或本次固定候选，不接受任意同版本程序。

版本仍为 `0.2.0-rc.1`，不推进 stable。apfix6 是针对 teslabox3 已编译的外置模块，随固定内核组件一起安装，不要求用户再手动替换；不改 iwd 管理策略、不强制卸载在线驱动。`token_busy` 仍列为内测已知问题，不将未完成的全网卡实测冒充通过。

修正 Radxa 内核安装后镜像解压的严格校验：冻结 DEB 内的 gzip vmlinuz 与 `zz-uncompress-kernel` 生成的原始 Image 分别绑定已核实长度和 SHA-256，仅接受这两组固定字节。任意重新封装、长度变化、篡改或错误设备树仍拒绝，失败不切换主程序。此修正只更新维护控制脚本，不重新编译已冻结主程序、更新助手、内核或 apfix6；原失败回执和旧内核恢复记录保留，重新验收后才允许开放新更新入口。

首次登记交接还需以干净设备和单部 iPhone 实测：手机发现 TeslaBox CarPlay、主动连接和手机侧配对确认、自动热点交接、真实视频首帧，以及拒绝、超时、取消、关闭功能、中途断电和配置冲突恢复。无屏配对方式无需管理页核对数字；隔离 D-Bus 测试不代替真实 iPhone 提示。`installation-ready`、服务运行状态和合成首帧均不代替真实手机视频及浏览器呈现。

Windows 回归、前端 DOM 测试及 ARM64 交叉编译已完成开发验证。隔离 Linux 安装/回退、Debian ARM64 工具执行、干净首装、正式旧版 OTA、真实 NAS 上传读回、iPhone 会话和车机 USB 录像仍须分别验收。开发测试包与占位下载描述不能作为用户安装入口。

无线网卡、蓝牙和驱动存在设备差异；协议支持不等于所有 NAS 品牌或网络组合均已验证。尚未完成的下载会重试整项归档，本候选暂不支持断点续传。

升级应保留本机原有设置与合法身份，不复制其他设备的私有配置。软件 MFi 身份经维护者私下分发，不包含在公开附件中，也不表示为每台设备签发新的 Apple 身份。

正式发布后应仅使用对应固定安装入口和签名清单，不沿用历史 RC 安装脚本。稳定版发布需另行确认。

2026-10-14 首登修订仅生成新的固定内部候选，不覆盖此前冻结的主程序或附件。临时 iAP 发现对照已由真实 iPhone 确认设备出现；该结果不代表完整登记、PAN 或视频首帧通过。新主程序必须与绑定其 SHA-256 的签名内核政策配套部署，保持原启动保护和成对回退；普通 beta/stable 索引在最终验收及授权前不切换。
