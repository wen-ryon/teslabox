# TeslaBox 0.1.32 内测版：首装与 MT7922 修复

本次内测重点是让重装系统的 ROCK 3A 用户直接安装当前内测版，并修复 MT7922 首装包缺少 Wi-Fi 固件的问题。

## 首装与无线网卡

- 内测版专用安装脚本直接下载 `0.1.32-beta` 首装包，安装后默认使用内测更新通道。
- 修正 MT7922 检测：同时识别 `14c3:0616` 和 `14c3:7922`，避免已插卡却提示未检测到。
- 新的 MT7922 附件包含 Wi-Fi 驱动、两份 MT7922 Wi-Fi 固件、蓝牙驱动和固件；安装前逐项校验，缺失或摘要不符时停止。
- 安装测试内核仍需用户在交互式终端明确输入 `INSTALL MT7922`。安装完成后，确认车辆没有通过 USB 写入，再手动重启。

## 适用范围与验证

- 普通网页 OTA 只更新 TeslaBox 主程序，**不会**安装或更换内核、驱动和固件。已有系统如需补装 MT7922，必须使用单独的补装脚本。
- 本版先作为内测版验证；需要分别确认首装后版本号、Wi-Fi 扫描/连接、热点、蓝牙、重启后的状态以及 USB Gadget。蓝牙驱动模块加载不等于蓝牙功能已经通过实机验证。
- 旧内核仍保留供启动故障时回退。不要在车机正在写入或车辆行驶时进行内核安装和重启。
