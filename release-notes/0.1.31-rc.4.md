# TeslaBox 0.1.31 RC4：本机 WiFi 自动化控制

RC4 在内测版中加入 `teslaboxctl wifi` 命令，供板内可信脚本查看已保存的网络与当前连接、扫描 WiFi、连接已保存或新网络，以及开关已保存网络的自动连接。命令通过本机 Unix Socket 调用 TeslaBox 服务，不向局域网或 FRP 开放；访问权限限于 root 和 `teslabox-automation` 用户组。

连接 WPA/WPA2 网络时，密码从标准输入读取，不放入命令行参数。设备不支持 AP+STA 并发且热点正在使用无线网卡时，连接操作默认拒绝断开热点；只有明确传入 `--confirm-ap-disconnect` 才允许切换。请通过有线连接进行实机验证，避免远程管理连接中断。

本轮仍为 ROCK 3A / Radxa Debian 11 ARM64 内测版，保留 RC3 的 Debian 安全仓固定快照首装方案。旧程序可能无法在设置中心识别 RC 版本；已安装用户应使用本轮经过 SHA-256 校验的本地升级命令，不应重复运行首装脚本。升级前请确认车辆未写入、USB Gadget 未承担传输，升级后检查 `teslaboxctl -v`、WiFi 列表与扫描、AP 租约、服务健康及重启后的 USB Gadget。未经真实用户验证，不推进 stable。
