# TeslaBox 0.1.23 正式版

这是一次覆盖录像播放、长视频导出、Tesla SEI、页面交互、日志诊断、启动链路和完整首装环境的大版本更新。建议用户先确认车辆未在写入录像并拔掉 OTG，再从“设置中心 → 系统更新”完成安装和重启。

## 网页更新与媒体运行时

- 网页更新包首次同时携带本版完整 Rockchip 媒体运行时，现有用户不再需要单独通过 SSH 更新 FFmpeg。
- 媒体包包含 H.264/HEVC RKMPP 编解码、MPP、RGA 缩放/叠加/VPP、libass、subtitles 和固定 Noto CJK 字体，覆盖播放、转码、时间及 Tesla 仪表信息绘制所需能力。
- 整个 ARM64 程序继续接受长度、SHA-256 与 Ed25519 签名校验；内置媒体包还会再次校验摘要、路径和文件类型，并在暂存目录完成能力探测后原子替换。
- TeslaUSB 核心状态机优先启动，媒体组件更新不会抢占车辆上电后的首次 Gadget 绑定机会；新版启动失败仍由独立更新助手自动恢复旧程序。

## 录像播放与时间线

- 修复压缩画质在跨分钟播放、跳转最后一个片段以及播放中拖动进度条时回弹、回到片段开头或卡在错误总时长的问题。
- 录像总时长改为依据实际可播放媒体边界收敛，避免列表显示 10:06、实际只能播放到 10:03 后反复鬼畜。
- Tesla SEI 使用缓存和相邻片段预取，跨分钟自动切换或跳转后可以继续显示，不再阻塞视频主播放链路。
- 在线播放新增 Tesla 风格仪表栏，显示录像时间、档位、时速、方向盘角度、转向灯、刹车、电门深度以及手动/AP/FSD 状态；方向盘、颜色和转向灯节奏随录像数据变化。

## 自定义导出

- 自定义剪辑改为可拖动两端的录像时间线，同时保留开始和结束时间输入；取消固定两分钟上限，长录像按绝对时间和分钟媒体边界分段导出。
- 多路合成按每个摄像头自己的时间偏移处理，使用有界 RKMPP 解码并分段合成，减少长导出后半段逐渐卡顿、掉帧和不同视角漂移。
- 高保真多路合成使用 HEVC RKMPP；单路原画和多路源文件导出继续保留，无需转码时直接下载原 MP4。
- 支持三种信息位置：左上角行车记录仪时间、画面上方独立信息栏、顶部居中的高透明悬浮信息栏；Tesla 仪表可绘制档位、时速、方向盘、转向灯、刹车、电门和 AP/FSD。
- 优化导出文件名、大小预估、历史导出保留与再次下载，并支持下载后立即清理或按数量保留。

## 页面与日志中心

- 新增“特斯拉车机兼容模式”，用页面内选择器替代车机浏览器无法弹出的原生下拉框。
- 概览、录像、设置、日志和耗时按钮补充统一加载状态，避免接口尚未返回时误判存储或服务未初始化。
- 日志中心默认读取 50 条，重新划分 TeslaBox、USB 枚举、网络热点和视频转码来源，增加中文诊断摘要，同时保留内核原文与错误码。
- 修复宽屏日志仍在约 660 px 提前换行的问题。

## 删除、空间和导出历史

- 录像列表支持进入删除模式后点击整张卡片多选，红色边框标识选择结果；全选只作用于已保存/哨兵录像，最近录像仍按单段删除。
- 已保存和哨兵录像按完整事件目录删除，包含视频、event.json、缩略图等元数据；删除流程会同步回收快照空间并按需要安全重启。
- 设置中心可配置导出文件下载后立即清理或保留数量，并可重新下载仍保留的历史导出。

## 启动、Gadget 与兼容性

- TeslaUSB 核心状态机提前启动，Web、认证、网络和媒体管理初始化不再占用冷启动的 Gadget 关键路径。
- 保留原厂 Gadget 冲突服务屏蔽、单次冷启动绑定、UDC 唯一性检查、OTG 安全窗口以及健康检查失败回滚，不增加运行期反复解绑/重绑。
- 录像浏览不再要求 OTG 已连接；手机、电脑或 FRP 网络访问可独立查看录像和导出。
- 非标准测试构建允许安装维护者签名的正式版本，避免测试版用户必须先手工改版本号。

## 首装与 MT7922 蓝牙

- 首装包同步安装本版程序、更新助手、Gadget/AP 组件以及完整 FFmpeg/MPP/RGA/libass/字体环境。
- MT7922 仍为可选测试内核，默认不安装；用户必须先输入明确确认文本安装 MT7922 Wi-Fi。
- 只有 MT7922 Wi-Fi 安装成功后，脚本才会再次询问是否安装蓝牙驱动；仅输入 `Y`/`y` 才安装已验证的 `5.10.160teslabox2`、对应 Wi-Fi backports、`btusb/btrtl`、MT7922 蓝牙固件和 BlueZ。
- 不选择蓝牙不会下载或安装蓝牙内核组件；本版不包含个人使用的蓝牙 HID、音频 Profile 或手机热点自动触发服务。

## 安全边界

- 网页更新不会更新内核、无线驱动、systemd 或执行下载来的 Shell/DEB；MT7922 与蓝牙驱动仅存在于有明确交互确认的首装流程。
- 仍须使用独立 Type-C 供电，并在上电前插好车机 OTG；不要为了测试在 ROCK 3A 已开机后热插 OTG 供电路径。
