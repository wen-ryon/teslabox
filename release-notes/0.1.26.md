# TeslaBox 0.1.26 内测版

> **内测警告：不建议普通用户更新。** 本版本调整了 USB Gadget 与存储维护的核心生命周期，只面向能够现场观察车机枚举、必要时物理断电恢复的测试设备。请勿在即将长途行驶或无法接触板子的情况下安装。

## Gadget 与存储维护安全

- 新增跨进程存储维护锁，主服务、独立 Gadget 启动命令和空间维护不能再并发绑定或写入同一个虚拟盘。
- 维护过程中持续阻止 Gadget 重新绑定；异常退出或断电后保留可诊断状态，避免服务重启后在维护未完成时盲目恢复 USB。
- Gadget 启动同时校验本次开机的安全暂停状态，降低独立启动命令绕过主服务限制的风险。

## 快照预留空间

- 统一快照运行期保留策略：默认至少保留 8 GiB 且不低于数据盘的 5%。新初始化设备额外保留 4 GiB 操作余量。
- 设置中心新增“修复快照预留空间”，只按实际缺口回收 exFAT 已确认空闲的簇，不再要求复制整个镜像或一次性准备与镜像等大的临时空间。
- 修复过程支持中断后重新测量并继续；只有重新校验达到安全门槛后，才允许解除维护状态并恢复 Gadget。
- 初始化页面会提前展示可写镜像容量和对外报告容量，并拒绝超过当前 MBR/镜像实现安全边界的设备。

## 安装与测试边界

- 本包可在设置中心直接检查、下载和安装；更新说明出现“内测版”时，请仅在测试设备上继续。
- 在线更新会替换 TeslaBox 主程序、内嵌网页和随包媒体运行时，不会更新内核、MT7922 Wi-Fi/蓝牙驱动或 AP 系统脚本。
- 已完成 Windows 构建环境下的全量单元测试、重点模块竞态测试、静态检查和 ARM64 发布构建检查；ROCK 3A 的冷启动、车机枚举、录像写入和维护中断恢复仍属于本轮内测验收范围。

## 建议重点反馈

- 冷启动后车机识别 USB 的耗时，以及是否出现多次闪现或反复枚举。
- 执行空间修复、温重启和断电重启后，Gadget 是否能在安全条件满足时恢复。
- 持续录像期间是否出现分钟文件保存间隔异常、录像缺段或页面快照失败。
