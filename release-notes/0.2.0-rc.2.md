# TeslaBox 0.2.0-rc.2 内测版

内部验收候选，不作为公开安装入口。只有维护者确认后才开放 beta，上传候选附件不表示已经开放更新。

## 本版重点

- 延续 0.2.0 的 CarPlay、NAS 上传、设置页面及录像播放能力，本轮重点收敛无线并发、CarPlay 恢复和诊断问题。
- 配套交付 RTL8852BE apfix7 与 teslabox3；内核组件及完整对应源码使用固定下载地址和摘要，避免用户额外手动替换模块。
- 纳入 RTL8852BE 启动接口角色修复：使用原生 `ap0`／`sta0` 双接口命名，防止二次自动改名，在 NetworkManager 启动前准备角色，避免上游连接抢占 AP 接口。OTA 补齐下次启动组件，不在线卸载驱动或重启网络；最终包的重启恢复仍须验收。
- 补充 CarPlay 浏览器状态探测、WebSocket、首个视频包、首帧和断开阶段日志，支持有限断网缓存与恢复补传，并纳入日志导出。
- 调整网络状态展示；CarPlay 占用热点时修改热点参数须明确确认中断，避免用户误操作。

## 升级与回退

- 必须使用与最终 RC2 候选配套的签名助手、主程序、组件和内核依赖清单，不沿用历史 RC1 命令或摘要。
- 维护助手先准备独立的 RC2 控制器和签名政策，不覆盖原 RC1 控制器或政策。旧主程序只按审核过的完整配对过渡；最终 RC2 仍严格核对 teslabox3 和 apfix7，不允许通过旧政策绕过。
- 恢复守卫未完整落盘并由 systemd 加载时，更新助手拒绝执行新安装；维护中断后只允许精确匹配本次成套输入的状态重新执行，不能仅凭版本字符串或单个助手摘要放行。
- 内核依赖安装、重启核对或主程序健康检查失败，不得显示升级成功；保留旧内核启动入口及成套回退材料。此链路须以最终 RC2 候选实测后方可开放。
- 维护安装与后续 OTA 是独立事务：维护自身出错会尝试恢复维护前文件；维护成功后的 OTA 失败不会自动撤销已完成的维护，保留兼容旧主程序的新助手及独立政策。
- 用户自行编译的内核模块不能跨内核 ABI 直接复用；未纳入冻结清单的自定义驱动不承诺自动迁移，不应在未知驱动状态下强行继续升级。
- 不将正在适配的 Debian 13／6.1 新系统纳入本次存量 Debian 11 升级。

## 已知边界

- 新安卓浏览器的短时播放、拖动、后台返回及关闭重开已获用户实测确认；原安卓浏览器出现的 Worker 初始化超时尚未确定原因，不宣称所有浏览器兼容性通过。
- 上述结果来自仍标识 RC1 的内部测试程序，不等于最终 RC2 的真实 OTA、冷启动、车机 USB 或全部 NAS 协议验收通过。
- 构建测试、公网下载校验与真实 OTA 验收分别记录；既有内核已为 apfix7 的板端更新，不能代替从旧内核首次安装的硬件验收。
- beta 开放须经维护者确认；本版准备不自动推进 stable。
