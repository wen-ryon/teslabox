# TeslaBox 0.1.14 WiFi/AP 兼容性热修复测试版

这是面向现有设备的测试更新。0.1.13 测试版已经撤回，本版不包含其“热点关闭时预创建 `ap0`”的实现。

## 修复内容

- 修复设置中心把 AP 信道设为“自动”时，服务端向 NetworkManager 写入非法信道 `0`，导致热点配置保存失败的问题。自动信道现在通过清空信道属性交给 NetworkManager 选择。
- 解除旧版 TeslaBox 上游 WiFi 配置中持久化的 BSSID 绑定，避免路由器切换射频、Mesh 漫游、接入点重启或同名热点 BSSID 变化后无法自动连接。
- 连接指定接入点时，BSSID 只约束当次激活，不再写死到 NetworkManager 连接配置。
- 新建上游 WiFi 配置后主动清空可能由 `nmcli device wifi connect` 固化的 BSSID，保留后续自动选点和漫游能力。
- 启动迁移只处理名称以 `TeslaBox-Upstream-` 开头的项目管理配置，不修改用户自行创建或维护的 WiFi 配置。
- 单个旧配置读取或迁移失败不会阻断其他配置清理，也不会阻止 TeslaBox 主服务启动。

## 更新后预期

- 设置中心选择 AP 自动信道后可以正常保存和启用，不再出现 `'0' is not a valid channel`。
- 旧版创建的上游 WiFi 配置会在服务启动时解除 BSSID 锁定；NetworkManager 可以重新选择当前可用的同名接入点。
- 已连接的上游网络不会因为清理 BSSID 属性而被主动断开。

## 安全边界

网页在线更新只下载并替换经过签名校验的 TeslaBox 主程序。本版不修改 USB Gadget 生命周期代码，不解绑或重新绑定 UDC，不重启 NetworkManager，不更新内核、无线驱动、FFmpeg/RKMPP 工具链，也不采用已经撤回的 0.1.13 AP 接口预创建方案。
