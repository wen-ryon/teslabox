# TeslaBox 0.1.29 稳定版

本版本优先保护车机持续录像，并修复 ROCK 3A 风扇首次导出 PWM 通道时的初始化顺序。在线更新只替换 TeslaBox 主程序、内嵌网页和受限媒体运行时，不修改内核、设备树、无线驱动或用户网络配置。

## 录像盘与快照空间保护

- 主服务启动时会在首次绑定 USB Gadget 前回收异常断电或进程退出遗留的 TeslaCam reflink 快照，避免无人访问页面时遗留快照持续消耗 XFS COW 空间。
- 运行中每次状态轮询都会检查外层 XFS 快照预留空间。未被播放或导出使用的快照会立即回收；仍在使用的快照会停止接受新请求，并在最后一个请求结束后回收。
- 低空间保护不会主动断开车机 Gadget，优先让车机继续写入。页面会展示降级原因，录像浏览和导出会在空间恢复前暂不可用。
- 修复低空间回收与新媒体请求并发时的租约竞争：快照从可借用状态撤销后，才开始物理卸载和删除。

## ROCK 3A 风扇

- 修复 PWM 通道首次导出时 `period=0`、`duty_cycle=0` 的写入顺序；不再先写可能被 sysfs 拒绝的零占空比。
- 保持 PWM 为可选能力：风扇硬件未就绪或初始化失败会记录诊断信息，但不会阻止 TeslaBox、录像盘或 USB Gadget 启动。

## 系统更新页面与发布维护

- 系统更新说明使用独立小字号，不再继承页面的大标题字号。
- 更新说明不再使用内部滚动区域，完整内容随设置页面自然展开。
- 发布流程支持将 Gitee Release 附件与可回退历史同步保留最近五个版本，避免旧附件占满配额后阻塞新版本上传。

## 更新提示

- 安装前请确认车辆未通过 OTG 写入；下载更新不影响车机，点击“安装并重启”时会暂时安全解绑 Gadget。
- 更新后应等待管理页面恢复并确认状态正常，再重新连接或启动车机录像。
