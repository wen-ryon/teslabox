# TeslaBox 0.1.19 离线录像浏览测试版

这是面向已安装 TeslaBox 的 ROCK 3A 设备的灰度测试更新，修复“板子未连接车机 OTG 时，网页无法浏览已有录像”的问题。请先在少量设备验证后再扩大更新范围。

## 离线录像浏览

- 设备在本次开机启动期未检测到 USB 主机枚举时，TeslaBox 会按既有安全策略主动解绑 Gadget，并且本次开机不再重新绑定 UDC。
- 在这个已明确暂停且未绑定的状态下，打开录像页面现在可以创建 TeslaCam 的 reflink 只读快照、扫描并播放已有录像。
- 离线浏览不会为了刷新录像重新绑定 USB Gadget，不会触发新的 OTG 枚举，也不会改变 ROCK 3A 的启动期安全窗口。
- 已有车机正在使用 Gadget 时，仍按原路径从一致性只读快照浏览，车机持续录像和网页读取不会直接并发访问原始镜像。

## 安全边界

- 只有 backing image 已就绪，且状态机能够证明“Gadget 已暂停并且当前未绑定”时，才允许离线创建快照。
- 未明确暂停的未绑定状态、故障状态、未就绪的数据盘以及任何未知状态仍会拒绝创建快照；不会把“没检测到 Gadget”误判为可以读写原始镜像。
- 本版不修改内核、USB 电源管理、systemd、udev、WiFi/AP 脚本或 FFmpeg/RKMPP 工具链。ROCK 3A 仍必须使用独立 Type-C 供电，并遵守 OTG 安全接线顺序。

## 测试范围与观察项

- 网页在线更新只替换签名校验后的 TeslaBox ARM64 主程序及内嵌页面。
- 请分别验证：不插 OTG 开机后浏览历史录像；正常连接车机时持续录像并浏览已完成片段；关闭浏览页后再次进入；以及在线更新后的车机重新枚举。
- 如果出现异常，请保留设置中心诊断日志、`journalctl -u teslabox.service` 和当前 Gadget 状态，不要在同一次开机中手工反复解绑、绑定 UDC。
