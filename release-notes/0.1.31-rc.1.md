# TeslaBox 0.1.31 RC1：首装与 MT7922 修复

本轮内测供重装系统的 ROCK 3A 用户直接首装。后续内测按 `0.1.31-rc.2`、`0.1.31-rc.3` 递增，验证完成后发布 `0.1.31` 正式版。

## 首装与无线网卡

- 专用首装脚本直接下载本轮 RC 首装包，安装后默认选择内测更新通道。
- 修正 MT7922 检测：识别 `14c3:0616` 和 `14c3:7922`，避免已插卡却提示未检测到。
- MT7922 包包含 Wi-Fi 驱动、两份 Wi-Fi 固件、蓝牙驱动与固件，安装前校验文件摘要。
- 安装测试内核仍须在交互终端输入 `INSTALL MT7922`；确认车机不在写入后再重启。

## 更新与验证

- 本轮首装的程序支持通过内测通道发现并安装后续 `rc.N` 版本；同一基础版本的正式版高于所有 RC。
- 普通网页 OTA 只更新 TeslaBox 主程序，不安装内核、无线驱动或固件。已安装系统若需补装 MT7922，请使用独立补装脚本。
- 请验证首装后版本号、Wi-Fi 扫描与连接、热点、蓝牙、重启后状态和 USB Gadget。蓝牙模块可加载不等于蓝牙功能已通过实机验证。
- 旧 `0.1.31-beta` 程序尚不支持 RC 版本比较，不能依赖其网页 OTA 自动发现本轮 RC。

旧内核保留供启动故障时回退。不要在车机正在写入或车辆行驶时安装内核、重启设备。
