# 录像时长静默更新接口

沿用现有录像列表接口及鉴权：`GET /api/v1/video-sessions`。

新增可选查询参数：`metadata_only=true` 跳过媒体激活，仅读取当前内存索引及已校准缓存，不创建快照；重复传入 `session_id` 可筛选指定会话。分页及响应结构不变，前端每批最多 50 个会话。

新增响应字段 `items[].duration_pending`（布尔值）：是否仍有未完成的时长校准。即使 `duration_state=unavailable`，也可能仍为 true，不能提前停止轮询。

前端每 5 秒静默查询待校准会话，失败保留原显示并下轮重试；只能合并响应 `snapshot_id` 与卡片快照一致且仍在当前列表的对象。无快照返回空编号，禁止覆盖已有列表。更新时长文字与结束时间，不重建卡片、不修改播放器详情和导出范围。分页响应沿用现有字段；普通列表请求行为不变。

验证覆盖：读取缓存不激活媒体；部分文件不可读取但仍存在待校准文件；切换快照/列表后丢弃旧响应；请求失败后重试；播放和删除选择不阻止文字更新。
